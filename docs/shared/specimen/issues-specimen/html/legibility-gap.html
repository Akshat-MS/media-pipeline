Gap 3 — Why the legibility check can’t be done from these previews
Every specimen is 1920×1080. Any preview pane that is narrower shrinks it. In a typical ~1456px-wide pane that is 76% scale — so 25px code has been shown to us at 19px, and 20px footer text at 15px. Judging “is this readable” from a shrunk image tells you nothing about the real thing, and the error runs in the dangerous direction: text that survives shrinking looks safe, while the true test is a projector at the back of a room.

only 25px and 20px are genuinely in question — the headings are safe at any size
The two-minute check: open specimen_navy_v1.html in a browser, press F11 for full screen on a 1080p display, and sit back at normal viewing distance. If the matrix digits and the level-3 bullets read comfortably, set typography.legibility_verified_fullscreen: true and the contract is approved. If they don’t, the fix is one line — raise the scale base from 31 to 33 or 35, and every size rederives.
