Problem 2 — Red/green carries the meaning, and it collapses
Your source decks encode request vs assignment as red vs green arrows. The right-hand column simulates deuteranopia (the most common red–green deficiency, ~6% of men). Colour is the only channel carrying the distinction, so when it collapses, the meaning is gone.

The durable fix is redundant encoding: never let colour be the only channel. Dashed vs solid carries the same distinction, so the diagram still reads in greyscale, on a bad projector, or for a colour-blind student.
